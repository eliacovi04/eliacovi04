## ABOUT ME

I'm a Computer Engineering MSc student at the University of Trieste, following the **Robotics & AI** curriculum.

I'm interested in building software that bridges computation and the physical world, with a particular focus on:

- Robotics and autonomous systems
- Embedded software and real-time systems
- Robot kinematics and trajectory planning
- Control systems and machine learning

> Software that interacts with the physical world.

## CURRENTLY WORKING ON

- **Robotics:** Manipulator control, inverse kinematics and trajectory planning.
- **Embedded Systems:** Vehicle telemetry and low-level software development.
- **ROS 2:** Learning robotic middleware, communication and simulation.
- **Computer Vision:** Exploring perception systems for robotic applications.
